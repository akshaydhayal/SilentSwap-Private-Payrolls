# SilentSwap Payroll - Private Payouts on Solana

Live Project Link: [https://silent-swap-private-payrolls.vercel.app/](https://silent-swap-private-payrolls.vercel.app//)

A privacy-focused dApp for automated payroll and bulk payouts on Solana. Built for the **Privacy Hackathon 2026**, this platform leverages the **SilentSwap Protocol** to ensure that employee payment histories remain private and unlinked on-chain.

## 🚀 Key Features

- **Anonymous Recipient Aliases**: Recipient names are never stored on-chain. Instead, they use auto-generated aliases (e.g., `Recipient-1`) to prevent public identity leaks.
- **Bulk Selection UI**: Intuitively select multiple recipients from your saved list and execute batch payments.
- **Private SOL Payouts**: Uses SilentSwap's ephemeral facilitator accounts to break the on-chain link between the employer and the employee.
- **On-Chain Status Tracking**: Tracks `last_payment_timestamp` and `total_payments` directly in the management program for internal auditing without revealing the actual transaction details.
- **Real-Time Feedback**: Integrated `react-hot-toast` notifications providing instant success messages and links to the Solana Explorer.

## 🏗️ Hybrid Architecture

SilentSwap Payroll uses a unique "Dual-Network" strategy to balance feature-rich management with high-security privacy:

1.  **Management Layer (Solana Devnet)**: 
    - Custom **Anchor Program** (`9ideARSj...`)
    - Stores recipient metadata (Department, Category, Active Status).
    - Tracks payment counters and timestamps.
    - **Cost**: Extremely low (Devnet SOL).
2.  **Execution Layer (Solana Mainnet)**:
    - Powered by the **SilentSwap Protocol**.
    - Transfers real SOL privately.
    - Uses ephemeral bridges to obfuscate payment paths.
    - No direct link between your main wallet and recipients.

---

## 🔐 Privacy Mechanism

1. **Obfuscation**: Each payout utilizes an ephemeral facilitator account generated by SilentSwap.
2. **Identity Protection**: Recipient names are replaced by aliases in the management UI.
3. **Transaction Privacy**: Destination transactions on Solana Mainnet are not directly searchable as "Payroll" unless you hold the private management records.

## 🚦 Getting Started

### Prerequisites
- Node.js 18+
- Solana Wallet (Phantom/Solflare)
- EVM Wallet (MetaMask/Rainbow)

### Installation
1. **Clone and Install**:
```bash
git clone https://github.com/akshaydhayal/SilentSwap-Private-Payrolls.git
cd SilentSwap-Private-Payrolls/app
npm install
```

2. **Configure Environment**:
Create `app/.env.local`:
```env
NEXT_PUBLIC_SILENTSWAP_ENV=staging
NEXT_PUBLIC_SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
NEXT_PUBLIC_INTEGRATOR_ID=
```

3. **Run Locally**:
```bash
npm run dev
```
